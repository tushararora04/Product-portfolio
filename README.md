# Tushar Arora - Product Portfolio

A static portfolio site with an interactive Three.js particle field and product case-study deck.

## Preview locally

From this folder, run:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Before publishing

Replace the email address and add your LinkedIn, GitHub, resume, and any Figma case-study links in `index.html`. The card content and modal case-study summaries live in `app.js`.
